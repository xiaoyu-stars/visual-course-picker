# 📚 可视化选课助手

单文件网页应用：可视化管理课程、可视化课表、自动检测时间冲突，专为研究生选课设计。

**首次打开是完全空白的**，请通过「新增课程」或「批量导入」添加自己的课程后使用。所有数据仅保存在你的浏览器本地（`localStorage`），不上传到任何服务器。

## ✨ 功能特性

- **课程管理**：添加、编辑、删除课程，每门课可设多个时间段（支持每周 / 单周 / 双周 / 区间周次）
- **可视化课表**：周一~周日 × 12 节网格，已选课程自动排版，同一格多门课自动并排显示
- **冲突检测**：实时检测时间冲突，懂单双周规则（单周课与双周课同时段不算冲突；1-8 周和 9-16 周的接力课也不算冲突）
- **个人培养方案**：按课程编号分组展示培养计划内的课程，支持按学期分组浏览、选班、查看进度
- **多维度筛选**：按上课星期、课程类型（必修/选修）、开课学期组合筛选
- **批量导入**：粘贴文本即可，支持多种分隔符
- **数据持久化**：所有数据保存在浏览器 `localStorage`，无需后端
- **一键导出**：导出文本版课表分享给同学
- **零隐私泄漏**：仓库内不含任何预设课程数据——每个人的课表都是自己加的

## 🚀 使用方法

直接用浏览器打开 `index.html` 即可，无需任何后端或安装步骤。

```bash
# 或启动一个简单的本地服务器（推荐，避免某些浏览器对 file:// 的限制）
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 📝 数据格式说明

每个课程对象结构：

```js
{
  id: "唯一 id",
  name: "课程编号 课程名（班级）",   // 如 "ABC1234 课程示例（01班）"
  teacher: "教师姓名",
  credit: 学分,
  location: "默认地点",
  note: "备注信息",
  sessions: [
    { day: 1, start: 1, end: 2, weeks: "1-16", location: "教学楼 101" }
  ],
  color: 0              // 0-7 颜色索引
}
```

### 周次语法

`weeks` 字段支持丰富的写法，自动识别：

| 写法 | 含义 |
| --- | --- |
| `"all"` 或 `""` | 每周 |
| `"单周"` / `"双周"` | 全部单/双周 |
| `"1-8"` / `"9-16"` | 第 1-8 周 / 9-16 周 |
| `"1-15单周"` / `"2-16双周"` | 区间 + 单/双周 |
| `"1,3,5,7,9,11,13,15"` | 显式周次列表 |
| `"13-14"` | 第 13-14 周（如 MBA 周末班） |

冲突判断支持以上所有写法，自动计算重叠周次。

### 课程时段格式

粘贴导入时使用：`课程名, 教师, 学分, 周一1-2节;周三3-4节, 地点`

多个时段用分号分隔，星期使用"周一~周日"，节次使用"1-2节"或"3节"。

## 🧩 自定义数据

应用不预置任何课程。你可以：

1. **在网页上手动添加/编辑课程** —— 点「新增课程」按钮，逐门录入；数据自动保存到 `localStorage`
2. **批量粘贴文本** —— 点「批量导入」按钮，按下方的格式一次粘贴多门课
3. **直接编辑 `index.html`** —— 如果你想修改默认值（如 KEY 名称、颜色表、时段映射），打开源码改对应常量即可

清空浏览器存储后，下次打开仍会从空白启动。

## 🌐 浏览器兼容

支持现代浏览器（Chrome / Edge / Firefox / Safari 最近两个大版本）。纯原生 HTML/CSS/JS，无任何依赖。
